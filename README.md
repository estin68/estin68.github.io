# estin68.github.io

👋 Personal developer profile, hosted on [GitHub Pages](https://estin68.github.io).

## About

A single-page, fun-but-professional developer profile — terminal-style hero, light/dark
theme toggle, experience timeline, skills, and stats. No build step; it's plain HTML/CSS/JS.

## Local preview

Just open [`index.html`](index.html) directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Pushing to `master` triggers the [`pages.yml`](.github/workflows/pages.yml) GitHub Actions
workflow, which deploys the site to GitHub Pages automatically.
